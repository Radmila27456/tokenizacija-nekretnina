# Tokenizacija nekretnina

Početni koncept i prezentacijska stranica projekta tokenizacije nekretnina, planiranog za mrežu Polygon.

## Trenutačni status

Repozitorij sadrži statičnu informativnu stranicu (`index.html`). U njemu još nema pametnog ugovora, registracije nekretnina, izdavanja tokena ni aplikacije za transakcije. Stranica nije ponuda udjela u nekretninama.

## Cilj projekta

Istražiti kako se podaci i prava povezana s nekretninama mogu dokumentirati i, uz odgovarajuću pravnu i tehničku provjeru, prikazati blockchain tehnologijom. Model prava, provjera vlasništva, odgovornosti sudionika i tehnički standard tek trebaju biti definirani.

## Sadržaj

- `index.html` — javna prezentacijska stranica
- `LICENSE` — licenca repozitorija

## Sljedeći koraci

1. Opisati konkretan slučaj uporabe i pravni model s odgovarajućim stručnjacima.
2. Utvrditi koje se informacije smiju javno objaviti i što token predstavlja.
3. Tek potom dokumentirati specifikaciju, izraditi ugovor i testirati aplikaciju.

Ovaj projekt nije NFTNAFAKA i ne koristi njezine NFT ugovore, slike ni SFT nagrade.
